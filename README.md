# 🧮 Minha Calculadora

Uma calculadora web simples, funcional e visualmente agradável, desenvolvida com HTML, CSS e JavaScript. O projeto foi criado para praticar lógica de programação, manipulação do DOM e desenvolvimento de interfaces interativas com uma experiência dinâmica para o usuário.

## 📌 Sobre o projeto

Esta calculadora oferece uma interface intuitiva para realizar operações básicas com recursos extras como:

- cálculo de soma, subtração, multiplicação e divisão
- inversão de sinal
- limpeza do visor
- exclusão do último caractere
- alternância entre tema claro e escuro

O objetivo principal é demonstrar habilidades em desenvolvimento front-end, organização de código e interação com elementos da interface.

## ✨ Funcionalidades

- Operações matemáticas básicas
- Botão para inverter o valor exibido
- Botão para apagar o último caractere
- Botão para limpar completamente o display
- Tema claro e escuro

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone <url-do-repositorio>
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd minha-calculadora
   ```

3. Abra o arquivo `index.html` no navegador.

## 📁 Estrutura do projeto

- `index.html` — estrutura da interface da calculadora
- `style.css` — estilização e comportamento visual
- `script.js` — lógica das operações e interação com os botões
